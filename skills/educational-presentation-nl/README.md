# educational-presentation-nl

Een agent-skill voor **evidence-based educatief presentatieontwerp** in het Nederlands.

Deze skill is een volledig Nederlandse lokalisatie van de
[`educational-presentation`](https://github.com/guia-matthieu/clawfu-skills/tree/main/skills/content/educational-presentation)
skill uit de [ClawFu Skills](https://github.com/guia-matthieu/clawfu-skills)
bibliotheek (MIT-licentie).

## Wat de skill doet

Maakt van een AI-agent een expert in het ontwerpen van cognitief geoptimaliseerde,
toegankelijke presentaties voor onderwijs en training. Gebaseerd op:

- **Cognitive Load Theory** (Sweller)
- **Mayers 12 principes voor multimediaal leren**
- **Gagné's 9 instructiegebeurtenissen**
- **C.R.A.P.-ontwerpprincipes** (Robin Williams)
- **WCAG 2.1 AA** toegankelijkheidsnormen

## Inhoud

| Bestand | Inhoud |
|---|---|
| `SKILL.md` | Hoofdinstructies: filosofie, principes, workflow, checklists, metadata |
| `references/quick-reference.md` | Snelle referentiekaart (30-secondenchecklist, Mayer, Gagné, C.R.A.P., enz.) |
| `references/slide-templates.md` | 25+ kant-en-klare slidetemplates per type slide |
| `references/before-after.md` | Voor/na-transformaties van 'Death by PowerPoint' naar cognitief optimaal |
| `references/validation.md` | Volledige validatiechecklist (174 punten) met scoring |

## Installatie

Kopieer de map `educational-presentation-nl` naar je skills-directory, bijvoorbeeld:

```bash
cp -r educational-presentation-nl <your-skills-directory>/
```

Of voeg de map toe aan je agent als skills-directory.

## Taal & register

- Alles is in het Nederlands.
- Standaard wordt de informele vorm **je/jij** gebruikt (conform Mayers
  personalisatieprincipe voor trainingscontexten). Pas dit aan naar **u** voor
  formele, zakelijke presentaties.
