# Snel referentiekaart - Educatieve presentatie

## 🚀 Ultrasnel starten

### De 3 gouden regels
1. **Visueel + vertelling** (nooit tekst + vertelling)
2. **1 slide = 1 idee** (chunking verplicht)
3. **Ontwerp = leermiddel** (geen decoratie)

---

## ⚡ 30-secondenchecklist (per slide)

```
❓ Heeft deze slide ÉÉN duidelijke boodschap?
❓ Is er een relevante afbeelding/visueel?
❓ Is de tekst minder dan 10 woorden?
❓ Is het lettertype ≥ 24pt?
❓ Is het contrast ≥ 4,5:1?
❓ Is alles uitgelijnd op een raster?
```

**6 × ✅ = slide goedgekeurd**
**<5 × ✅ = opnieuw bewerken**

```
≥ 24pt (broodtekst)           < 20pt

Links uitgelijnd              ALL CAPS
Vet voor nadruk               Onderstreept (= link)
Max 2 lettertypen             5+ lettertypen
```

## 🌈 Kleuren - 60-30-10-regel

```
60% → Achtergrond (wit, lichtgrijs)
30% → Secundair (structuur)
10% → Accent (highlight)

Minimumcontrast: 4,5:1
Tool: webaim.org/contrastchecker
```

## 📐 Magische formules

### Ideale lettergrootte
```
Afstand publiek (meters) / 7,5 = minimale grootte (pt)

Vb: publiek op 7,5m → 7,5/7,5 = 1" ≈ 30pt minimum
```

### Sildeduur
```
1 eenvoudige slide = 30-60 seconden
1 complexe slide = 2-3 minuten (met progressive disclosure)

Presentatie van 15 min = MAX 15-20 slides
```

### Cognitieve belasting
```
Intrinsic Load (inhoud) + Extraneous Load (ontwerp) = Total Load

Doel: Minimaliseer Extraneous om Germane (leren) te maximaliseren
```

## 🎬 Progressive Disclosure - gebruiksaanwijzing

### PowerPoint
```
1. Selecteer tekst/object
2. Tabblad Animaties
3. "Verschijnen" of "Vervagen"
4. Effectopties > "Per alinea"
5. Trigger: "Bij klik"
```

### Google Slides
```
1. Selecteer tekst/object
2. Invoegen > Animatie
3. "In vervagen"
4. Trigger: "Bij klik"
5. ✅ "Per alinea"
```

**Wanneer?**
- Lijsten ≥ 3 items
- Complexe diagrammen
- Sequentiële processen

---

## ♿ Toegankelijkheid - 5 must-haves

```
1. Contrast ≥ 4,5:1 (normale tekst)
2. Contrast ≥ 3:1 (grote tekst 18pt+)
3. Alt-tekst op ALLE afbeeldingen
4. Lettertype ≥ 24pt
5. Geen kleur alleen voor betekenis (voeg vorm/tekst toe)
```

## 🧠 Geheugensteun cognitieve belasting

```
🟢 GERMANE LOAD (GOED)
   → Echte leerinspanning
   → Integratie van kennis
   → Opbouw van mentale schema's
   ✅ TE MAXIMALISEREN

🟡 INTRINSIC LOAD (NEUTRAAL)
   → Inherente moeilijkheid van het onderwerp
   → Beheerd via chunking
   → Tijdelijke scaffolding
   ⚖️ TE BEHEREN

🔴 EXTRANEOUS LOAD (SLECHT)
   → Inspanning om het ontwerp te begrijpen
   → Visuele afleidingen
   → Redundantie tekst/vertelling
   ❌ TE MINIMALISEREN
```

## 📏 Afstand & marges

```
Minimale marges: 0.5" (1,27cm) aan elke kant
Afstand tussen elementen: ≥ 0.25" (0,64cm)
Regelafstand (line height): 1,2-1,5x lettergrootte

Witruimte ≠ verloren ruimte
Witruimte = visuele ademruimte = cognitieve helderheid
```

## ⚡ Ultrasnelle beslisbomen

### "Hoeveel slides?"
```
Presentatie 10 min → 10-15 slides
Presentatie 20 min → 20-30 slides
Presentatie 45 min → 40-50 slides
+ oefen-/feedbackslides
```

### "Hoeveel tekst?"
```
Titel: 1 zin (5-10 woorden)
Broodtekst: MAX 3-5 kernwoorden
Details: in sprekersnotities
```

### "Welke afbeelding?"
```
Relevant voor de inhoud? → Houden
Mooi maar decoratief? → Verwijderen
Afleidend? → Verwijderen
Lage kwaliteit? → Vervangen
```

## 📞 Snelle hulp

**Slide te vol?**
→ Chunk in 3 slides

**Publiek leest in plaats van luistert?**
→ Tekst → Notities + visueel op slide

**Ontwerp vlak/saai?**
→ Voeg contrast toe (grootte, kleur, gewicht)

**Diagram te complex?**
→ Progressive disclosure (5 kliks)

**Grafiek verwarrend?**
→ Vereenvoudig tot 1-3 kernvariabelen
